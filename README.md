# 🏥 Harsha Hospital — Healthcare Appointment Booking Platform

A modern, full-stack healthcare appointment booking platform designed for **Harsha Hospital, Hiriyur, Karnataka**.

The platform provides patients with a simple way to explore healthcare services, view doctor availability, and book appointments online, while hospital administrators can manage doctors, services, schedules, patients, and appointments through a secure admin dashboard.

---

## 🚀 Features

### 👨‍⚕️ Patient Features

- User registration and secure login
- Browse available doctors
- Explore healthcare services
- View doctor availability
- Online appointment booking
- Real-time appointment slot validation
- Appointment confirmation
- Appointment cancellation
- Appointment rescheduling
- View upcoming appointments
- View appointment history
- Manage patient profile
- Download/print appointment confirmation

### 🏥 Hospital Admin Features

- Secure admin authentication
- Admin dashboard
- Appointment management
- Doctor management
- Service management
- Department management
- Schedule management
- Patient management
- Appointment status management
- Calendar-based appointment view
- Gallery management
- Website content management
- Hospital information management

### 📅 Appointment Management

The system prevents:

- Double booking
- Booking unavailable slots
- Booking past dates
- Booking outside doctor schedules
